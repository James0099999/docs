## Who we are?

我们是面向在线博彩运营商与平台的赌场游戏 RESTful API 服务商。我们提供稳定、可直接用于生产环境的 API 层，助您在无需重建核心基础设施的情况下上线并扩展游戏业务。

凭借在 iGaming 行业超过 **10\+ 年**的实战经验，我们将技术深度与以运营商为先的服务相结合。
