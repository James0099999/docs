---
title: "Error Codes"
---

| Code | Description |
| :-- | :-- |
| `UNDER_MAINTENANCE` | 服务器正在维护中 |
| `INTERNAL_SERVER_ERROR` | 服务器内部错误 |
| `VALIDATION_ERROR` | 请求数据格式错误 |
| `SERVICE_EXCEPTION` | 发生服务异常 |
| `TOKEN_NOT_FOUND` | 未找到认证令牌 |
| `TOKEN_INVALID` | 认证令牌无效 |
| `PERMISSION_ERROR` | 无访问权限 |
| `PROVIDER_ERROR` | 供应商错误 |
| `PARAMETERS_INVALID` | 参数无效 |
| `CALLBACK_ERROR` | 回调错误 |
| `SERVER_IS_BUSY` | 服务器负载错误 — 超过并发调用限制 |
| `IP_NOT_ALLOWED` | 请求来自非白名单 IP 地址 |
| `AGENT_NOT_FOUND` | 未找到代理商信息 |
| `USER_NOT_FOUND` | 未找到用户信息 |
| `GAME_NOT_FOUND` | 未找到游戏信息 |
| `POINT_NOT_ENOUGH` | 代理商积分余额不足 |
| `BALANCE_NOT_ENOUGH` | 用户积分余额不足 |
| `PROVIDER_NOT_FOUND` | 未找到供应商信息 |
| `BONUSCALL_DOUBLE` | 该玩家已有进行中的奖励调用 |
| `BONUSCALL_ALEADY_ENDED` | 奖励调用已结束 |
| `ROUND_NOT_FOUND` | 未找到局/回合信息 |
| `CURRENCY_NOT_SUPPORTED` | 不支持该货币 |
