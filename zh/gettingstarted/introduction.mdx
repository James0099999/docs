API 是一套协议与工具，可让赌场平台接入我们的游戏系统，并通过统一的 RESTful 接口为玩家提供多样化内容——包括老虎机与真人游戏。无论您运营单一赌场站点，还是管理多家运营商网络，该 API 都能提供所需控制能力：启动游戏、管理玩家钱包，以及开展促销活动。

## 主要功能

### 灵活的 RTP 设置

您可按业务需求自定义玩家回报率（RTP）。RTP 可按各游戏供应商分别配置，范围为 75% 至 99%，从而对玩家群体的游戏经济模型实现精细控制。

### 奖金与免费旋转功能

您可为玩家发放指定金额的奖金额度或免费旋转，以促进新用户注册并奖励忠实玩家。API 同时支持免费旋转奖金与保赢奖金，便于灵活设计促销活动结构。


### 多币种与多语言支持

API 开箱即支持多种货币与语言，无需自建本地化层即可服务全球用户。玩家可使用偏好语言浏览内容，并以本币交易，降低摩擦、提升参与度。

### 无缝对接

我们直接与您现有平台对接。在无缝对接模式下，由您的后端通过实时钱包回调管理玩家余额，无需人工干预。 **_我们仅支持 Seamless Wallet API。_**

<Tip>
  接入前可先体验线上演示游戏。 请访问 [sandbox.igamingace.com](https://sandbox.igamingace.com/) 浏览可用老虎机产品。
</Tip>

我们采用极低的收入分成模式，在降低您运营成本的同时，仍可为玩家提供功能完善的游戏体验。

目录中的每款游戏均具备安全、经审计且有保障的 RTP 与波动率配置。玩家可信任结果公平性，您也可依赖平台上稳定、可预期的表现。

我们的支持团队会监控您的接入情况，并随时协助诊断与解决问题。您无需独自排查——团队会与您协作，直至问题得到解决。
